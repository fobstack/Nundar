Regulatorische Erklärung. Gültig ab: Oktober 2026. Bescheinigende Stelle: unsere Qualitätsabteilung.

## RoHS 3 (EU 2015/863)

Wir bescheinigen hiermit, dass alle Titan-Verbindungselemente, Präzisions-Passschrauben, Muttern und kundenspezifischen CNC-Bauteile, die nach ASTM B348, AMS 4928 und ISO-Normprofilen gefertigt werden, die Richtlinie 2011/65/EU der Europäischen Union und die Änderungsrichtlinie (EU) 2015/863 (RoHS 3) strikt einhalten.

Verbotene gefährliche Stoffe, nachweislich unter den Grenzwerten:

| Stoff | Nachgewiesener Gehalt |
| --- | --- |
| Blei (Pb) | < 0,1 % |
| Quecksilber (Hg) | < 0,1 % |
| Cadmium (Cd) | < 0,01 % |
| Sechswertiges Chrom (Cr VI) | < 0,1 % |
| Polybromierte Biphenyle (PBB) | < 0,1 % |
| Phthalate (DEHP, BBP, DBP, DIBP) | < 0,1 % |

## REACH (EG 1907/2006), Kandidatenliste der SVHC

Gemäß Artikel 33 der Verordnung (EG) Nr. 1907/2006 enthalten unsere Teile keinen der besonders besorgniserregenden Stoffe (SVHC) der aktuellen Kandidatenliste der Europäischen Chemikalienagentur (ECHA) in Konzentrationen von mehr als 0,1 Massenprozent.

## Konfliktmineralien (Section 1502)

Die Schmelzwerke unseres Rohtitans führen vollständige Conflict Minerals Reporting Templates (CMRT), die belegen, dass kein Material aus der Demokratischen Republik Kongo oder angrenzenden Konfliktgebieten stammt.
