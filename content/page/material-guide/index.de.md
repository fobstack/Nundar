Dieser Leitfaden nennt die chemische Zusammensetzung, die Streckgrenzen, die Einsatztemperaturen und die Normspezifikationen der Titansorten für Luft- und Raumfahrt und Industrie, aus denen wir eng tolerierte Verbindungselemente fertigen. Jede Sorte hat ihren eigenen Abschnitt, gefolgt von einem Vergleich von Titan mit Edelstahl und Luftfahrtaluminium.

## Grade 5 (Ti-6Al-4V)

**Hochfeste Alpha-Beta-Titanlegierung für die Luft- und Raumfahrt.** Typ: Alpha-Beta-Legierung. Spezifikationen: UNS R56400, ASTM B348, AMS 4928.

Die unbestrittene Referenz für hoch beanspruchte mechanische Verbindungselemente, bei denen ein extremes Festigkeits-Gewichts-Verhältnis und die Ermüdungslebensdauer entscheidend sind.

### Zusammensetzung von Grade 5

Grenzwerte der chemischen Zusammensetzung:

| Chemisches Element | Massenanteil nach Norm (%) |
| --- | --- |
| Titan (Ti) | Rest (88-90 %) |
| Aluminium (Al) | 5,5 – 6,75 % |
| Vanadium (V) | 3,5 – 4,5 % |
| Eisen (Fe) | ≤ 0,40 % |
| Sauerstoff (O) | ≤ 0,20 % |
| Kohlenstoff (C) | ≤ 0,08 % |

### Eigenschaften von Grade 5

| Eigenschaft | Wert |
| --- | --- |
| Dichte | 4,43 g/cm³ (44 % leichter als Stahl) |
| Zugfestigkeit (Rm) | 895 – 1.050 MPa |
| Streckgrenze (Rp0,2) | 828 – 920 MPa |
| Bruchdehnung | 10 – 14 % |
| Härte | 32 – 36 HRC (320 HV) |
| Maximale Dauereinsatztemperatur | 400 °C (752 °F) |
| Korrosionsbeständigkeit | Ausgezeichnet (Meerwasser, Chloride, Salpetersäure) |

### Typische Baugruppen aus Grade 5

- Strukturschrauben für Flugzeugrümpfe unter hohen g-Lasten
- Radträgerbolzen für Formel 1 und Supersportwagen
- Nutzlast-Spannringe für Raumfahrzeuge
- Hydrofoils und Antriebsstränge im Regattasport

## Grade 2 (Reintitan)

**Unlegiertes Titan, das Arbeitspferd für reine Korrosionsbeständigkeit.** Typ: Reintitan, Alpha. Spezifikationen: UNS R50400, ASTM B348, ASTM F67.

Ideal, wenn Korrosionsimmunität in oxidierenden Säuren, feuchtem Chlor oder aggressiver Meeressole Vorrang vor höchster Klemmkraft hat.

### Zusammensetzung von Grade 2

Grenzwerte der chemischen Zusammensetzung:

| Chemisches Element | Massenanteil nach Norm (%) |
| --- | --- |
| Titan (Ti) | ≥ 99,2 % |
| Eisen (Fe) | ≤ 0,30 % |
| Sauerstoff (O) | ≤ 0,25 % |
| Kohlenstoff (C) | ≤ 0,08 % |
| Stickstoff (N) | ≤ 0,03 % |
| Wasserstoff (H) | ≤ 0,015 % |

### Eigenschaften von Grade 2

| Eigenschaft | Wert |
| --- | --- |
| Dichte | 4,51 g/cm³ |
| Zugfestigkeit (Rm) | 345 – 485 MPa |
| Streckgrenze (Rp0,2) | 275 – 380 MPa |
| Bruchdehnung | 20 – 28 % |
| Härte | 80 – 90 HRB (160 HV) |
| Maximale Dauereinsatztemperatur | 315 °C (600 °F) |
| Korrosionsbeständigkeit | Hervorragend (Meerwasser, feuchtes Chlor, Bleichlauge) |

### Typische Baugruppen aus Grade 2

- Verbindungselemente für Wärmetauscher in Chemieanlagen
- Flanschschrauben für Rohrleitungen in Entsalzungsanlagen
- Halterungen für Unterwassersensoren und geflutete Gehäuse
- Behältersysteme für Chlor und Hypochlorit

## Grade 23 (Ti-6Al-4V ELI)

**Titan mit besonders niedrigem Gehalt an interstitiellen Elementen (ELI) für Medizin und Kryotechnik.** Typ: Alpha-Beta, Medizin und Kryotechnik. Spezifikationen: UNS R56401, ASTM F136, AMS 4930.

Gewählt, wenn höchste Bruchzähigkeit bei kryogenen Temperaturen unter null oder strenge chirurgische Biokompatibilität vorgeschrieben ist.

### Zusammensetzung von Grade 23

Grenzwerte der chemischen Zusammensetzung:

| Chemisches Element | Massenanteil nach Norm (%) |
| --- | --- |
| Titan (Ti) | Rest |
| Aluminium (Al) | 5,5 – 6,5 % |
| Vanadium (V) | 3,5 – 4,5 % |
| Eisen (Fe) | ≤ 0,25 % |
| Sauerstoff (O) | ≤ 0,13 % (streng) |
| Kohlenstoff (C) | ≤ 0,08 % |

### Eigenschaften von Grade 23

| Eigenschaft | Wert |
| --- | --- |
| Dichte | 4,43 g/cm³ (44 % leichter als Stahl) |
| Zugfestigkeit (Rm) | 860 – 960 MPa |
| Streckgrenze (Rp0,2) | 790 – 860 MPa |
| Bruchdehnung | 12 – 18 % |
| Härte | 30 – 34 HRC (300 HV) |
| Maximale Dauereinsatztemperatur | 400 °C; Kryoeinsatz bis -250 °C |
| Korrosionsbeständigkeit | Überlegene Biokompatibilität und Beständigkeit gegen Salzlösung |

### Typische Baugruppen aus Grade 23

- Raketenleitungen für Flüssigstickstoff und Flüssigwasserstoff
- Chirurgische Roboterarme und Implantate für die Medizin
- Kryogene Vakuumsysteme für Tiefsttemperaturen
- Nicht magnetische Ausrüstung für den 7T-MRT-Betrieb

## Grade 7 (Ti-0.15Pd)

**Palladiumlegiertes Titan für reduzierende Säuren.** Typ: Alpha mit Palladium, einem Edelmetallzusatz. Spezifikationen: UNS R52400, ASTM B348.

Der Goldstandard zur Vermeidung von Spaltkorrosion in reduzierenden Säuren bei niedrigem pH-Wert und hoher Temperatur, in denen sich andere Metalle auflösen.

### Zusammensetzung von Grade 7

Grenzwerte der chemischen Zusammensetzung:

| Chemisches Element | Massenanteil nach Norm (%) |
| --- | --- |
| Titan (Ti) | ≥ 99,0 % |
| Palladium (Pd) | 0,12 – 0,25 % |
| Eisen (Fe) | ≤ 0,30 % |
| Sauerstoff (O) | ≤ 0,25 % |

### Eigenschaften von Grade 7

| Eigenschaft | Wert |
| --- | --- |
| Dichte | 4,51 g/cm³ |
| Zugfestigkeit (Rm) | 345 – 485 MPa |
| Streckgrenze (Rp0,2) | 275 – 350 MPa |
| Bruchdehnung | 20 – 26 % |
| Härte | 85 HRB |
| Maximale Dauereinsatztemperatur | 350 °C |
| Korrosionsbeständigkeit | Höchste Stufe (extreme Spaltbedingungen und reduzierende Säuren) |

### Typische Baugruppen aus Grade 7

- Prozesspumpen für Salz- und Schwefelsäure
- Spaltbehaftete Verbindungen in heißen Chloridmedien
- Geothermische Dampfförderbohrungen zur Energiegewinnung
- Offshore-Öl- und -Gasplattformen mit Sauergas (H2S)

## Titan, Edelstahl und Aluminium im Vergleich

Warum Konstrukteure tragende Verbindungselemente von Edelstahl 316 und legiertem Stahl auf Titan Grade 5 umstellen:

| Leistungskennwert | Titan Grade 5 (Ti-6Al-4V) | Edelstahl 316L | Luftfahrtaluminium 7075-T6 |
| --- | --- | --- | --- |
| Dichte (Masse) | 4,43 g/cm³ | 7,98 g/cm³ (+80 % schwerer) | 2,81 g/cm³ |
| Zugfestigkeit | 895 – 1.050 MPa | 550 – 680 MPa | 570 MPa (geringe Ermüdungsfestigkeit) |
| Festigkeits-Gewichts-Verhältnis | 214 kN·m/kg | 75 kN·m/kg | 202 kN·m/kg |
| Beständigkeit gegen Meerwasser / Chloride | 100 % lochfraßbeständig | Anfällig für Spaltkorrosion | Korrodiert im Salznebel |
| Magnetische Permeabilität | < 1,00005 (nicht magnetisch) | Leicht magnetisch nach Umformung | Nicht magnetisch |
