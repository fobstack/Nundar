Esta guía recoge la composición química, los límites elásticos, las temperaturas de funcionamiento y las especificaciones normalizadas de los grados aeroespaciales e industriales de titanio que mecanizamos para obtener fijaciones de tolerancias estrictas. Cada grado tiene su propia sección, seguida de una comparación del titanio con el acero inoxidable y el aluminio aeroespacial.

## Grado 5 (Ti-6Al-4V)

**Aleación aeroespacial de titanio alfa-beta de alta resistencia.** Tipo: aleación alfa-beta. Especificaciones: UNS R56400, ASTM B348, AMS 4928.

La referencia indiscutible para fijaciones mecánicas sometidas a grandes esfuerzos en las que son primordiales una relación resistencia-peso extrema y la vida a fatiga.

### Composición del grado 5

Límites de composición química:

| Elemento químico | Peso normalizado (%) |
| --- | --- |
| Titanio (Ti) | Resto (88-90 %) |
| Aluminio (Al) | 5,5 – 6,75 % |
| Vanadio (V) | 3,5 – 4,5 % |
| Hierro (Fe) | ≤ 0,40 % |
| Oxígeno (O) | ≤ 0,20 % |
| Carbono (C) | ≤ 0,08 % |

### Propiedades del grado 5

| Propiedad | Valor |
| --- | --- |
| Densidad | 4,43 g/cm³ (un 44 % más ligero que el acero) |
| Resistencia a la tracción (Rm) | 895 – 1.050 MPa |
| Límite elástico (Rp0,2) | 828 – 920 MPa |
| Alargamiento | 10 – 14 % |
| Dureza | 32 – 36 HRC (320 HV) |
| Temperatura máxima en servicio continuo | 400 °C (752 °F) |
| Resistencia a la corrosión | Excelente (medio marino, cloruros, ácido nítrico) |

### Conjuntos típicos en grado 5

- Tornillos estructurales de fuselaje aeroespacial para alta carga G
- Pasadores de mangueta de suspensión para Fórmula 1 y superdeportivos
- Anillos de sujeción de carga útil para vehículos espaciales
- Hidroalas y transmisiones de potencia para competición náutica

## Grado 2 (comercialmente puro)

**El titanio sin alear de uso general para una resistencia pura a la corrosión.** Tipo: alfa comercialmente puro. Especificaciones: UNS R50400, ASTM B348, ASTM F67.

Ideal cuando la inmunidad a la corrosión en ácidos oxidantes, cloro húmedo o salmuera marina agresiva tiene prioridad sobre una capacidad de apriete de resistencia ultraalta.

### Composición del grado 2

Límites de composición química:

| Elemento químico | Peso normalizado (%) |
| --- | --- |
| Titanio (Ti) | ≥ 99,2 % |
| Hierro (Fe) | ≤ 0,30 % |
| Oxígeno (O) | ≤ 0,25 % |
| Carbono (C) | ≤ 0,08 % |
| Nitrógeno (N) | ≤ 0,03 % |
| Hidrógeno (H) | ≤ 0,015 % |

### Propiedades del grado 2

| Propiedad | Valor |
| --- | --- |
| Densidad | 4,51 g/cm³ |
| Resistencia a la tracción (Rm) | 345 – 485 MPa |
| Límite elástico (Rp0,2) | 275 – 380 MPa |
| Alargamiento | 20 – 28 % |
| Dureza | 80 – 90 HRB (160 HV) |
| Temperatura máxima en servicio continuo | 315 °C (600 °F) |
| Resistencia a la corrosión | Suprema (agua de mar, cloro húmedo, lejía) |

### Conjuntos típicos en grado 2

- Fijaciones de intercambiadores de calor de plantas químicas
- Tornillos de bridas de tuberías de plantas desaladoras
- Soportes de sensores submarinos y carcasas en inmersión
- Sistemas de contención de cloro e hipoclorito

## Grado 23 (Ti-6Al-4V ELI)

**Titanio médico y criogénico de intersticiales extrabajos.** Tipo: alfa-beta, médico y criogénico. Especificaciones: UNS R56401, ASTM F136, AMS 4930.

Se selecciona cuando es obligatoria la máxima tenacidad a la fractura a temperaturas criogénicas bajo cero o una estricta biocompatibilidad quirúrgica.

### Composición del grado 23

Límites de composición química:

| Elemento químico | Peso normalizado (%) |
| --- | --- |
| Titanio (Ti) | Resto |
| Aluminio (Al) | 5,5 – 6,5 % |
| Vanadio (V) | 3,5 – 4,5 % |
| Hierro (Fe) | ≤ 0,25 % |
| Oxígeno (O) | ≤ 0,13 % (estricto) |
| Carbono (C) | ≤ 0,08 % |

### Propiedades del grado 23

| Propiedad | Valor |
| --- | --- |
| Densidad | 4,43 g/cm³ (un 44 % más ligero que el acero) |
| Resistencia a la tracción (Rm) | 860 – 960 MPa |
| Límite elástico (Rp0,2) | 790 – 860 MPa |
| Alargamiento | 12 – 18 % |
| Dureza | 30 – 34 HRC (300 HV) |
| Temperatura máxima en servicio continuo | 400 °C; servicio criogénico hasta -250 °C |
| Resistencia a la corrosión | Biocompatibilidad y resistencia salina superiores |

### Conjuntos típicos en grado 23

- Conducciones de nitrógeno líquido e hidrógeno líquido para cohetes
- Brazos robóticos quirúrgicos e implantes médicos
- Sistemas de vacío criogénicos de temperatura ultrabaja
- Equipos no magnéticos para funcionar en RM de 7 T

## Grado 7 (Ti-0.15Pd)

**Titanio mejorado con paladio para ácidos reductores.** Tipo: alfa con paladio, una adición de metal noble. Especificaciones: UNS R52400, ASTM B348.

El patrón de referencia para prevenir la corrosión por resquicios en entornos de ácidos reductores de pH bajo y alta temperatura en los que otros metales se disuelven.

### Composición del grado 7

Límites de composición química:

| Elemento químico | Peso normalizado (%) |
| --- | --- |
| Titanio (Ti) | ≥ 99,0 % |
| Paladio (Pd) | 0,12 – 0,25 % |
| Hierro (Fe) | ≤ 0,30 % |
| Oxígeno (O) | ≤ 0,25 % |

### Propiedades del grado 7

| Propiedad | Valor |
| --- | --- |
| Densidad | 4,51 g/cm³ |
| Resistencia a la tracción (Rm) | 345 – 485 MPa |
| Límite elástico (Rp0,2) | 275 – 350 MPa |
| Alargamiento | 20 – 26 % |
| Dureza | 85 HRB |
| Temperatura máxima en servicio continuo | 350 °C |
| Resistencia a la corrosión | Máxima (resquicios extremos y ácidos reductores) |

### Conjuntos típicos en grado 7

- Bombas de proceso para ácido clorhídrico y sulfúrico
- Uniones con resquicios expuestas a cloruros a alta temperatura
- Pozos de extracción de energía de vapor geotérmico
- Plataformas offshore de petróleo y gas con gas ácido (H2S)

## Comparación entre titanio, acero inoxidable y aluminio

Por qué los ingenieros pasan las fijaciones estructurales del acero inoxidable 316 y del acero aleado al titanio grado 5:

| Parámetro de prestaciones | Titanio grado 5 (Ti-6Al-4V) | Acero inoxidable 316L | Aluminio aeroespacial 7075-T6 |
| --- | --- | --- | --- |
| Densidad (masa) | 4,43 g/cm³ | 7,98 g/cm³ (+80 % más pesado) | 2,81 g/cm³ |
| Resistencia a la tracción | 895 – 1.050 MPa | 550 – 680 MPa | 570 MPa (mala resistencia a la fatiga) |
| Relación resistencia-peso | 214 kN·m/kg | 75 kN·m/kg | 202 kN·m/kg |
| Inmunidad al medio marino / cloruros | 100 % inmune a las picaduras | Propenso a la corrosión por resquicios | Se corroe en niebla salina |
| Permeabilidad magnética | < 1,00005 (no magnético) | Ligeramente magnético al trabajarlo | No magnético |

## Especificar un grado

Cualquiera de estos grados puede especificarse para una fijación fabricada bajo pedido: consulte la [fabricación a medida](/es/fabricacion-a-medida). Para estimar la masa que ahorra el cambio del acero al titanio grado 5, utilice las [calculadoras de fijaciones](/es/tools/calculadoras-de-fijaciones). Los documentos de inspección que acreditan el grado de un lote entregado se describen en [aseguramiento de la calidad](/es/aseguramiento-de-calidad).
